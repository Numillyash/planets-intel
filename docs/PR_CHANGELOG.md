# IntelBoard — PR changelog

## PR #71 — корпус, боезапас своих кораблей и гипотетическая полная заправка (27.10.2026)

- Горби (hull #70): исключаем VCR, противоречащие hullid, предельному числу лучей/торпедных установок, и не выводим торпедное вооружение у корпуса с нулём launchers.
- Собственные Gemini/Virgo: разъясняем generic ammo как fighters только при однозначном авианосном корпусе без torpedo tubes; сохраняем неизвестные значения и известный ноль.
- Warp 9 и Unlimited Fuel ограничивают движки: конкретное имя выводится, если допустим один вариант из каталога. Это проверяемый вывод, а не прямое наблюдение двигателя.
- 2803-980-1760=63 kt для Gorbie — только условный верхний mass budget при полном баке, а не подтверждённые fighters.
- Новая контрольная масса собственного Virgo: 2321-625-1550-106=40 kt, что совпадает с массой десяти Disruptor по 4 kt. Масса двигателей уже в hull; точный комплект требует других доказательств.
- Добавлены unit regression tests, типы данных, UI с происхождением приватного ammo, текстовые границы неопределённости и docs/handoff/2026-10-27-gorbie-hull-ammo-mass-constraint.md.
- CI/production проверять по live SHA; не публиковать частные игровые данные.

## PR #70 — шкала активности от полуночи с LOCAL/UTC-переключателем (2026-10-24)

- Обнаруженное пользовательским скриншотом неудобство двойной временной шкалы устранено: каждая диаграмма показывает одну выбранную ось с началом `00`, окончанием `24` и четвертными метками `06/12/18`.
- Выбор `LOCAL/UTC` циклически перестраивает **вместе** raw factual ticks, нормализованную density curve и линию NOW; общая легенда содержит обе текущие метки времени. Исторический UTC, backend и KDE sigma не изменяются.
- CSS привязывает подписи оси к фактическим x-координатам графика: первая метка точно на x=0, последняя на x=300, промежуточные каждые 6 часов.
- Браузерный регрессионный тест покрывает UTC+3 с проверкой x raw tick и NOW, взаимный поворот KDE, возврат в LOCAL, desktop/mobile и ход часов.
- Обязательный русский handoff `docs/CONTINUE_HERE.md` и тематический документ `docs/handoff/2026-10-24-turn-timing-midnight-axis.md` обновлены в том же PR. Статус CI/merge/deploy определяется только живой GitHub проверкой; private production parity не заявлена.

## PR #69 — минималистичный маркер времени и удаление вводящей в заблуждение ready latency (2026-10-24)

- После обратной связи на реальном Turn timing убрана надпись NOW из каждого SVG, жёлтая линия и единственный образец общей легенды стали сплошными. Синхронные локальные/UTC часы сохранены.
- Вместо двух медиан оставлена информативная медиана *first observed open after host (this game)*; `ready after host` больше не рендерится, потому что значение может быть отрицательным ещё до ошибочного приведения к `0m` в интерфейсе.
- `formatDelay` больше не маскирует отрицательные значения нулём: отображает `—`, сохраняя легитимный неотрицательный 0m. Backend observations и KDE неизменны.
- Обновлены Chromium fixture и assertions: legend-only NOW, solid SVG marker, clock advance, mobile, misleading latency. PR handoff: `docs/CONTINUE_HERE.md` + тематическая записка `docs/handoff/2026-10-24-turn-timing-legend-ready-latency.md`.
- CI, merge, deployment: **проверить по фактическому последнему head**; production acceptance не заявлена.
